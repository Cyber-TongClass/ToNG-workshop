# Digits dataset

1,797 handwritten digits, each represented by an 8 x 8 grayscale image.
The last CSV column is the digit label (0 through 9); pixel values are 0 to 16.

Source: the Optical Recognition of Handwritten Digits dataset by E. Alpaydin
and C. Kaynak, distributed in scikit-learn 1.5.2 as `digits.csv.gz`.
UCI dataset: https://doi.org/10.24432/C50P49 (CC BY 4.0).
Source file: https://github.com/scikit-learn/scikit-learn/blob/1.5.2/sklearn/datasets/data/digits.csv.gz
The data is bundled so training and grading require no network or scikit-learn.
